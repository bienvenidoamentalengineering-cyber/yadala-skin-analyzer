## TABLA 4 · ESTRUCTURA DE REEL POR FORMATO

### FÓRMULA FIJA PARA LOS 3 FORMATOS

```
FORMATO 45s:
├── HOOK          (0–4s)   → Frase contracorriente de la Tabla 2
├── MINI-HOYO     (4–13s)  → La creencia popular explicada con empatía
├── CLIFFHANGER   (13–18s) → "Y aquí está lo que nadie te dice..."
├── HISTORIA      (18–40s) → Realidad biológica + cómo actúa Yadala
├── FRASE FRACTAL (40–42s) → Una sola frase que sintetiza todo
└── CTA DOBLE     (42–45s) → Palabra clave + compartir

FORMATO 25s / 5 CLIPS:
├── Clip 1 (0–4s)   → HOOK narrado + overlay texto
├── Clip 2 (4–10s)  → MINI-HOYO comprimido
├── Clip 3 (10–16s) → CLIFFHANGER
├── Clip 4 (16–22s) → IDEA PRINCIPAL (sin desarrollo)
└── Clip 5 (22–25s) → PREGUNTA DISONANTE (sin CTA de palabra)

FORMATO 7s VIRAL:
├── Pantalla 1 (0–3s) → Primera parte del hook
├── Pantalla 2 (3–6s) → Giro / contracorriente
└── Pantalla 3 (6–7s) → Logo Yadala + silencio
```

## REGLAS DEL AGENTE IA PARA USAR ESTA BASE

1. **Un reel = una fila** de la Tabla 2. No mezclar estructuras.
2. **El hook del reel 45s** = versión expandida del hook 7s de la misma fila.
3. **La realidad biológica** de la Tabla 2 = el bloque HISTORIA/CONTEXTO del reel 45s.
4. **Siempre cerrar** con la firma: *Yadala · Bioestimulación facial · 4 generaciones · La piel no se corrige. Se despierta. ✦*
5. **Nunca mencionar** "mascarilla", "fórmula de triple acción", ni los tres ingredientes juntos.
6. **Línea por zona:**
   - PREVENT → zonas 07, 08 (frente, entrecejo)
   - RECOVER → zonas 01, 02, 06, 10, 12 (surco, mejilla, ojeras, boca, mandíbula)
   - RECLAIM → zonas 03, 04, 05, 09, 11, 13, 14, 15 (SMAS, pómulo, párpado, labios, mentón, papada, óvalo, cuello)
