## TABLA 3 · FÓRMULA DE REEL — 3 FORMATOS

```
FORMATO 45s:
├── HOOK          (0–4s)   → Frase contracorriente
├── MINI-HOYO     (4–13s)  → Creencia popular con empatía
├── CLIFFHANGER   (13–18s) → "Y aquí está lo que nadie te dice..."
├── HISTORIA      (18–40s) → Realidad biológica + Yadala
├── FRASE FRACTAL (40–42s) → Síntesis de una sola frase
└── CTA DOBLE     (42–45s) → Palabra clave + compartir

FORMATO 25s / 5 CLIPS:
├── Clip 1 (0–4s)   → HOOK narrado + overlay
├── Clip 2 (4–10s)  → MINI-HOYO comprimido
├── Clip 3 (10–16s) → CLIFFHANGER
├── Clip 4 (16–22s) → IDEA PRINCIPAL
└── Clip 5 (22–25s) → PREGUNTA DISONANTE

FORMATO 7s VIRAL:
├── Pantalla 1 (0–3s) → Primera parte del hook
├── Pantalla 2 (3–6s) → Giro / contracorriente
└── Pantalla 3 (6–7s) → Logo Yadala + silencio
```

## REGLAS DEL AGENTE IA

1. Un reel = una fila de la Tabla 2. No mezclar estructuras.
2. El hook del reel 45s = versión expandida del hook 7s de la misma fila.
3. La realidad biológica = bloque HISTORIA/CONTEXTO del reel 45s.
4. Siempre cerrar: `Yadala · Bioestimulación facial · 4 generaciones · La piel no se corrige. Se despierta. ✦`
5. **NUNCA:** 'mascarilla', 'fórmula de triple acción', tres ingredientes juntos, 'antiedad'.
6. Líneas: PREVENT → frente, entrecejo · RECOVER → surco, ojeras, boca, mandíbula · RECLAIM → SMAS, pómulo, párpado, labios, mentón, papada, óvalo, cuello, sistemas.
7. Los 4 territorios son marcos de series semanales — no mezclar territorios en una misma semana.
