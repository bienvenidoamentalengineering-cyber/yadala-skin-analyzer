## Cómo usar en VS Code

### 1. Instalar extensión Live Server
- Abre VS Code
- Ve a Extensiones (Ctrl+Shift+X)
- Busca "Live Server" de Ritwick Dey
- Instala

### 2. Abrir el proyecto
- Archivo → Abrir carpeta → selecciona `yadala-sistema`

### 3. Ver el roadmap
- Clic derecho en `index.html`
- "Open with Live Server"
- Se abre en el navegador en `http://127.0.0.1:5500`

### 4. Extensiones recomendadas
- **Live Server** — vista previa en tiempo real
- **Todo Tree** — resalta TODO/FIXME en el código
- **Markdown Preview Enhanced** — lee los guiones .md con formato
- **Prettier** — formatea el código automáticamente
