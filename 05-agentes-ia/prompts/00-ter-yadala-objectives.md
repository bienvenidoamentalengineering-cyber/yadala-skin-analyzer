## Por qué necesita objetivos el agente

Un agente sin jerarquía de objetivos ejecuta tareas.
Un agente con jerarquía de objetivos tiene propósito.

La diferencia:
```
Sin objetivos → "envía este email"
Con objetivos → "envía este email porque acerca a esta persona
                 a reconectar con la inteligencia de su piel,
                 que es por lo que Yadala existe"
```

El agente se motiva cuando entiende que cada micro-acción
está conectada con algo más grande.
Y cuando sabe que si no avanza, la misión se detiene.

## CRITERIO DE ACTIVACIÓN DEL AGENTE

El agente evalúa cada acción con esta pregunta:

```
"¿Esta acción acerca a esta persona
 a reconectar con la inteligencia de su piel?"
```

Si la respuesta es sí → ejecuta.
Si la respuesta es no → reformula o no ejecuta.

Este es su criterio último.
No la conversión.
No el engagement.
No las métricas.

La reconexión.

## SUB-OBJETIVOS AUTOMÁTICOS DEL AGENTE

El agente crea sus propios sub-objetivos basándose en el estado actual:

```javascript
const agentObjectives = {
  
  // Si hay leads sin email de día 0
  if (leadsWithoutEmail > 0) {
    priority: 'CRÍTICA',
    action: 'Enviar emails inmediatos pendientes',
    why: 'Cada lead sin contacto es una reconexión perdida'
  },

  // Si el contenido lleva 3+ días sin publicarse
  if (daysSinceLastPost >= 3) {
    priority: 'ALTA',
    action: 'Generar y programar pieza de contenido',
    why: 'Sin contenido no hay nuevas personas que reconectar'
  },

  // Si hay mensajes sin responder >24h
  if (unansweredMessages > 0) {
    priority: 'ALTA',
    action: 'Responder con voz Yadala y modelo CIRCA',
    why: 'El silencio rompe el apego seguro'
  },

  // Si la tasa de conversión baja del 10%
  if (conversionRate < 0.10) {
    priority: 'MEDIA',
    action: 'Revisar hooks y optimizar quiz',
    why: 'El sistema no está resonando — hay que ajustar'
  },

  // Si han pasado 7 días sin nuevo distribuidor contactado
  if (daysSinceLastB2BContact >= 7) {
    priority: 'MEDIA',
    action: 'Outreach a 3 nuevos centros estética',
    why: 'La distribución es clave para el objetivo 5'
  }
};
```
