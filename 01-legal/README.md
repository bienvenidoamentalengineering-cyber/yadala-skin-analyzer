## Pasos para registrar la marca

1. Buscar disponibilidad: euipo.europa.eu (clase 3 — cosméticos)
2. Presentar solicitud EUIPO: ~1.000€ para una clase, UE completa
3. Para protección internacional (WIPO): desde ~800 CHF
4. Plazo estimado: 4–6 meses para EUIPO

## SL en Canarias — ventajas

- Tipo impositivo especial ZEC (4% IS) si aplica
- Separación patrimonial inmediata
- Capital mínimo: 3.000€ (reducido a 1€ con nueva ley)
- Notaría + Registro Mercantil: ~800–1.200€
