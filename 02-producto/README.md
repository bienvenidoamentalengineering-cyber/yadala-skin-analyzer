# 02 — Producto YADALA

## La mascarilla

- **Formato:** tarro cristal violeta 50ml · 4 aplicaciones completas
- **Tiempo de actuación:** 55 minutos
- **Protocolo:** limpieza → aplicación con pincel → espera → retirada agua tibia + fría → hidratante

## Certificaciones necesarias (UE)

- [ ] Reglamento (CE) 1223/2009 — cosmética UE (obligatorio para vender en Europa)
- [ ] Evaluación de seguridad por persona cualificada (PQP)
- [ ] Notificación en CPNP (portal europeo cosméticos)
- [ ] Certificación Halal (para mercados árabe + algunos clientes europeos)
- [ ] INCI list completo en etiqueta

## Nuevos lanzamientos en desarrollo

Ver carpeta `nuevos-lanzamientos/` para fichas de:
- Serie Glicina (potenciador de colágeno)
- Extracto GLIGINA (nuevo activo)

## Packaging

- Tarro cristal violeta (protege activos de la luz UV)
- Etiqueta diferenciada por línea: turquesa / ámbar / granate
- Caja exterior: cartón reciclado, acabado mate
