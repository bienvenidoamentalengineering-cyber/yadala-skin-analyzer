## Proceso de producción de un reel

1. **Idea** → elegir hook del banco-hooks.md
2. **Guión** → usar agente-contenido con el hook elegido
3. **Grabación** → vertical, buena luz, sin fondo cargado
4. **Edición** → CapCut o Premiere (subtítulos siempre)
5. **Caption** → agente-contenido genera caption + hashtags
6. **Publicación** → programar con Meta Business Suite o Later
7. **Análisis** → métricas a los 3 días → informe agente-analítica
