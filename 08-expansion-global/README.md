## Pipeline de ventas (7 fases)

1. **Prospección** → identificar centros target
2. **Primer contacto** → email personalizado (agente B2B)
3. **Seguimiento** → 3 días si no hay respuesta
4. **Demo** → sesión gratuita de prueba
5. **Muestra** → envío físico si hay interés
6. **Propuesta** → condiciones comerciales
7. **Firma** → contrato distribuidor + formación

## Certificación Halal — prioritaria

Necesaria para: UAE, Marruecos, Arabia Saudita, Indonesia, comunidades 
musulmanas en Europa (UK, Francia, Bélgica, Países Bajos).

Organismos certificadores:
- **Europa:** HCA (Halal Certification Authority)
- **Internacional:** IFANCA
- **Marruecos:** IMANOR

Proceso: ~3–6 meses, requiere documentar cada ingrediente.
